Method

The scorer never sees who wrote the article.

Outlet name, masthead references, byline, author bio, source URL and boilerplate are stripped before a single word reaches the model. A score describes the text in front of it, not the reputation attached to it.

Counted, not felt

Signals are observable features of the text: how many named sources, how many quoted words to each side, where the opposing view first appears, how many claims trace to a document. A number built from countable things can be argued with. A vibe cannot be defended, only asserted.

Two signals — headline-to-body congruence and steelman quality — need model judgement. They are marked J wherever they appear, with confidence and run-to-run spread beside them.

Blinding is the whole methodological claim, and it is the first thing that should be attacked. The stripping code is in the public repo and the stripped text is recoverable for any published score.

What this does not do

  • It does not evaluate whether reporting is accurate. Nothing here fact-checks a claim.
  • It does not score opinion sections, columns, or editorials.
  • It does not republish articles. Scores link out; raw text is stored locally for analysis and never served.
  • It does not generate prose about people. Published output is counts the code computed and verbatim quotes with links.
  • It does not cover three of Florida’s largest papers, which are hard-paywalled and blocked to automated fetching. That is a gap in the data, not a finding about them.
  • Omission analysis needs three or more outlets on a story. Single-outlet stories get sourcing and language signals only.

Reproduce anything

git clone https://github.com/nrhhds/SecondSource
python score.py --url <source-url> --rubric 0.1 --seed 7

No composite score

There is no single number, and there will not be one until the calibration tests pass. A composite is the only thing anyone repeats, which makes it the number that has to be earned last rather than first.

Nobody approves a score

The pipeline publishes without review. There is no queue where a human sees a score and decides whether it runs. A published score is withdrawn only under an enumerated reason code, and every withdrawal is logged publicly.
